# Направление интерфейса

Рабочая тетрадь для вязания: светлая страница, боковая навигация, цветовые образцы пряжи и заметный таймер. Главный акцент — сами изделия и цвет нити, без декоративных графиков.

Палитра: белый #FFFFFF, фон #F6F5F8, чернильный #30263B, фиолетовый #70548D, сиреневый #EEE8F4, зеленый #496C5C. Шрифт системный Avenir Next с доступным sans-serif fallback; крупные заголовки, обычный регистр, табличные цифры времени. Слева навигация, справа контент, формы в доступных модальных окнах. На телефоне навигация превращается в горизонтальную панель.

Пустое состояние приглашает добавить первую пряжу и проект. Вымышленные работы не выдаются за данные пользователя. Фотографии загружает сам пользователь; вместо отсутствующего фото — спокойная условная иллюстрация с категорией изделия.
