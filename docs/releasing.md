# Выпуск обновлений

Приложение проверяет GitHub Releases репозитория [roux-afk/knitting_helper](https://github.com/roux-afk/knitting_helper). Обновления работают только в установленной версии для Windows: они используют `electron-updater` и файл `latest.yml` из выпуска.

## Как выпустить версию

1. Внесите изменения и проверьте `npm test`, `npm run typecheck`.
2. Поднимите `version` в `package.json` (например, `0.3.1`) и закоммитьте.
3. Создайте тег и отправьте его:
   ```sh
   git tag v0.3.1
   git push origin main v0.3.1
   ```
4. GitHub Actions (`.github/workflows/release.yml`) на Windows соберет установщик, проверит серверную часть и опубликует выпуск: `Petelka-<версия>-windows-x64-setup.exe`, `.blockmap` и `latest.yml`. Тег должен совпадать с версией в `package.json`, иначе сборка остановится.
5. Установленные приложения найдут выпуск при следующей проверке.

Не удаляйте `latest.yml` и не подменяйте файлы уже опубликованного выпуска: приложение сверяет контрольную сумму. Исправленную версию выпускайте под новым номером.

## Что видит пользователь

- При запуске (через 15 секунд) приложение тихо проверяет обновления. Без интернета ничего не показывается; в настройках появляется отметка, если есть новая версия.
- **Мастерская → Проверить обновления…** или **Настройки → Обновления**: проверка, описание изменений, скачивание с прогрессом, кнопка «Установить и перезапустить».
- Перед установкой сохраняется `backups/before-update-<старая>-to-<новая>-….json`. Если копию создать не удалось, обновление не устанавливается.
- Установка тихая, права администратора не требуются при установке «для текущего пользователя». Данные в `%APPDATA%\Петелька` не затрагиваются; схема базы обновляется при первом запуске с копией базы перед миграцией.

## Ограничения

- Первую версию с обновлением (0.3.0) нужно установить вручную. Предыдущие версии обновляться сами не умеют.
- Установщик не подписан сертификатом издателя. Проверка целостности — контрольная сумма SHA-512 из `latest.yml`, а источник — ваш репозиторий. Windows SmartScreen может предупредить при первой ручной установке.
- macOS: автоматическое обновление невозможно без подписи Apple. В приложении есть кнопка открытия страницы выпусков.
- Репозиторий должен оставаться публичным, иначе приложению понадобится токен доступа.
- Схема базы не должна откатываться: старая версия не откроет базу, созданную новой.
